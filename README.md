# VIEW2D_PMP

Seção 2D interativa do PMP: mapa em planta clicável + perfil sincronizado, com linha de corte rotacionável (4 ângulos, slider ou clique no mapa).

- **Mapa:** Hipsometria / Geologia real (CPRM + sills) / Satélite
- **Furos:** pontos no mapa e colunas projetadas no perfil (até 1,5 km da linha de corte), corpo intrusivo em vermelho
- Gráfico de espessura das formações na linha atual; tema escuro/claro
